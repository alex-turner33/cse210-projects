The objective of my platformer game is to touch the yellow cube in order to progress to the next level. To start a game you press start
or exit if you choose to end the game. You can move around using the ADW keys. A to go left, D to go right, and W to jump. The space bar controls the bullets
Each enemy has 3 lives and so does the player. Even though the player says it has 4 lives there is a bug I was unable to fix that makes it so it really
only has 3 lives. The enemies can kill you so avoid them. There are 3 levels get to the yellow cube in the level 3 means you have successful completed
the game. Good luck!
